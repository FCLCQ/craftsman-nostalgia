# 资源包来源与许可

[English](https://github.com/FCLCQ/craftsman-nostalgia/blob/main/docs/RESOURCE-PACK-SOURCES.en.md)

分发包携带 `CNFullTextures-CC.zip`，这是可以再分发的版本，包内自带 `LICENSES/MIT.txt` 与 `LICENSES/CC-BY-SA-4.0.txt`，`pack.mcmeta` 描述为“工匠怀古全覆盖材质(可分发)”。

## 内容构成

资源包共 3642 个条目，覆盖 `minecraft`、`tconstruct`、`botania`、`twilightforest`、`taiga`、`conarm` 等命名空间的贴图与模型。素材来自 ModernityExtra（MIT）与 Backport Everything（CC BY-SA 4.0），按来源文件保持原样，未做改写。声音与语言文件不纳入，由各模组自带资源与 1.12.2 原版提供。

`assets/tconstruct/textures/items/`、`assets/botania/textures|models|blockstates/` 等会与当前 Tinkers' Antique 2.13.0.x 生成贴图、Botania 贴图域冲突的覆盖不包含在此包内。

## 许可

资源包整体以 CC BY-SA 4.0 分发，来自 ModernityExtra 的 MIT 素材保留原许可，两份许可原文随包内 `LICENSES/` 提供。Minecraft 原版素材版权归 Mojang Studios，再分发需署名并以相同方式共享。

## 不纳入的来源

未附许可文件的 FFD 附加资源包、LGPL 的 Modernity Adjunct、GPL-3.0 的 Fabric Chests 与 LGPL-3.0-only 的 Modernity-f3 均未进入分发包。新增素材须先确认许可与整包兼容，再记录来源与改写范围。
