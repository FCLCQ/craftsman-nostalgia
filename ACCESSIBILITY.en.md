# Accessibility

[中文](ACCESSIBILITY.md)

This is a pack repository, so accessibility applies to documentation and release notes.

- All documents are Markdown, Simplified Chinese by default, with a parallel English version in `.en.md` files.
- Release notes use plain text and lists; images are not required to understand them.
- Mod lists, configuration notes and install steps do not rely on colour, and every table has a header row.
- Known limitation: in-game interfaces and rendering are determined by the installed mods and shaders; this project makes no accessibility commitment at that level.

Documentation problems (layout, missing English versions, dead links) can be reported as an issue.
